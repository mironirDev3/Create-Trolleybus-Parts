# Create: Trolleybus parts

This mod adds electric components and soon blocks to Create: PowerGrid that are functional and editable.

As of now, there are:

Rotary switches
Linear switches
LV Toggle switches

Planned:

Alternators
Pole Shoe (Sable only.)
Square small lightbulbs
Voltmeters and Ampermeters with negative and positive sides to display.
Square buttons

To be edited.
